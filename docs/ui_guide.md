# TodoMaster UI/UX 가이드

*작성일: 2026-02-22 | 작성자: UI/UX 디자이너*

---

## 1. 디자인 원칙

- **명확성**: 한눈에 파악할 수 있는 직관적 UI
- **일관성**: Material Design 3 가이드라인 준수
- **효율성**: 최소한의 탭으로 주요 기능 접근
- **접근성**: 충분한 색상 대비, 터치 영역 최소 48dp

## 3. 테마

### 라이트 테마
- 배경: `ColorScheme.surface` (밝은 흰색 계열)
- 텍스트: `ColorScheme.onSurface` (짙은 색)
- 카드 elevation: 1

### 다크 테마
- 배경: `ColorScheme.surface` (어두운 계열)
- 텍스트: `ColorScheme.onSurface` (밝은 색)
- 동일한 seed color 사용으로 일관된 팔레트

### 테마 전환
- 설정 화면에서 라이트 / 다크 / 시스템 설정 선택
- `SettingsProvider.isDarkMode`로 상태 관리

## 4. 타이포그래피

Material Design 3 기본 텍스트 스케일 사용:

| 스타일 | 용도 |
|--------|------|
| `headlineMedium` | 화면 제목 |
| `titleLarge` | 섹션 제목 |
| `titleMedium` | 할일 제목 |
| `bodyMedium` | 본문, 설명 |
| `bodySmall` | 보조 텍스트, 날짜 |
| `labelMedium` | 칩, 태그 |

## 5. 컴포넌트 스타일

### 카드 (TodoCard)
- `borderRadius: 12`
- `elevation: 1`
- 왼쪽 우선순위 색상 바 (4dp 너비)
- 완료 시 제목에 취소선 표시

### 버튼
- FAB: `borderRadius: 16`, 그림자 elevation 3
- ElevatedButton: Material 3 기본
- 우선순위 선택: FilterChip 사용

### 입력 필드
- `filled: true`, `fillColor: surfaceContainerLow`
- `borderRadius: 12`, 포커스 시 primary 색상 border
- `contentPadding: horizontal 16, vertical 14`

### 앱바
- `centerTitle: true`
- `elevation: 0` (flat)
- `backgroundColor: surface`

### 하단 네비게이션
- `BottomNavigationBarType.fixed` (4개 탭)
- 선택 색상: `primary`
- 비선택 색상: `onSurfaceVariant`

### Chip
- `borderRadius: 8`
- 우선순위 선택, 카테고리 필터에 사용

### SnackBar
- `SnackBarBehavior.floating`
- `borderRadius: 8`

## 7. 인터랙션 패턴

### 스와이프
- 할일 카드 좌측 스와이프 → 삭제 (빨간 배경 + 삭제 아이콘)

### 탭
- 할일 카드 탭 → 편집 화면 이동
- 완료 체크박스 탭 → 완료 토글 (애니메이션)
- 별표 아이콘 탭 → 중요 표시 토글

### FAB
- 홈 화면: 할일 추가 (`+` 아이콘)
- 카테고리 화면: 카테고리 추가

### 검색
- 앱바 검색 아이콘 탭 → 검색 모드 전환
- 실시간 필터링

---

## 8. 반응형 및 접근성

- 최소 터치 영역: 48 × 48 dp
- 텍스트 크기: 최소 14sp (bodyMedium)
- 색상 대비: WCAG AA 기준 준수 (4.5:1 이상)
- 다크모드: 모든 화면 지원
- `Semantics` 위젯으로 스크린 리더 지원 권장

---

## 9. 애니메이션

- 화면 전환: `go_router` 기본 전환
- 할일 완료 토글: 체크박스 애니메이션 + 취소선 페이드
- 목록 추가/삭제: `AnimatedList` 또는 `AnimatedSwitcher` 활용
- FAB: 확장/축소 애니메이션
